## The idea

PortfolioOS will serve as both my developer portfolio and my personal technical journal.

Projects will be the principal content. Each project will include feature demonstrations, explanations of the technology stack, architectural notes, and links to related articles.

## Two interfaces

The first interface will resemble a nostalgic desktop operating system.

A visitor will also be able to activate a modern version of the site. Both interfaces will use the same project and article content rather than maintaining two separate websites.

## Initial architecture

The first implementation uses:

- Astro for content-oriented pages
- Vue for interactive components
- TypeScript for application code
- Markdown for projects and articles
- Static deployment without a backend
