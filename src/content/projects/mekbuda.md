## Overview

I built Mekbuda as an owned digital home for a custom lighter art portfolio.

The project moves the work beyond the limitations of a social-media grid by giving each creation structured information, richer media, deliberate placement, and an individual presentation page. It also includes an authenticated administration workspace so the portfolio can be maintained without editing application code.

The public portfolio, design and media data model, validated management workflow, and core administrative experience are complete. Development can continue through final content, real project photography, short video loops, inquiry improvements, and future commission functionality.
