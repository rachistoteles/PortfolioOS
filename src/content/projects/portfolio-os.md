## Project overview

PortfolioOS is a developer portfolio presented through two visual systems.

The default interface resembles a nostalgic desktop environment. Visitors can switch to a modern presentation without leaving the website or loading a separate content system.

## Current state

The project structure and content system are being established.

## Planned implementation

- Interactive desktop windows
- Taskbar and Start menu
- Project explorer
- Blog explorer
- Modern visual mode
- Project feature galleries
- Video previews
- Responsive mobile interface
